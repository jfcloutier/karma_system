# Objects

## Objects of experiences

Objects are what experiences are about. All objects are objects of experiences.

An experience is represented either as a property or a binary relation.
A property associates an atomic value to an object.
A relation associates an object to another.

## Kinds of experiences

* Sensory experiences  - from reading sensor values
* Synthetic experiences  - from finding patterns (count, more, trend) in (observed, inferred) umwelt experiences
* Activation experiences - from planning to achieve goals (of persisting, impacting, creating experiences)
* Inferred experiences - from applying causal theories (to observed umwelt experiences to infer unobserved experiences)

## Types of objects

The cognitive architecture of the robot allows for 4 kinds of objects:

* Imagined objects
* Sensory objects
* Synthetic objects
* Activation objects

An object has a unique name (its identifier) which is a seemingly random sequence of characters, such as "a3876de25b8".

### Imagined object

An object imagined by the apperception engine:

* abduced to create a causal theory that makes sense of a history of observed umwelt experiences
* atomic in that its id is all that describes the object
* what inferred (umwelt) experiences can be about

### Sensory object

A sensor as a source of sensations:

* identified by a unique id
  * IR sensor in front
  * IR sensor in front
  * IR sensor in back
  * Touch sensor on the left
  * etc.

### Synthetic object

A set of observed umwelt experiences that were aggregated into a synthetic experience:

* the constituents of a synthetic experience (count, more or trend)
* represented and communicated as an atomic id (a function of the observed set)
* only the experiencing CA can interpret the object's id as a set of observations

### Activation object

A goal to be achieved:

* a goal is the desire to impact (persist, terminate, create) an experience
* an activation property assigns to the object a status (the goal is relevant, planned, executed...)
* its id is a function of the goal's impact and targeted experience

## Abstraction

All objects are sensory objects, or are objects transitively abstracted from sensory experiences.

For examples,

* the object of a sensory experience is the front IR sensor with read value 10
* the object in a synthetic trend experience as a set of sensory experiences (the distance read by the observed front IR sensor is decreasing)
* the object in a synthetic count experience as a set of trend experiences (there are two upward trend experiences observed in the umwelt)

## Epistemic isolation

The objects that populate the cognition of the robot are objects of its own experiences, not of ours.
There are no "floor" or "wall" or "food" objects cognized by the robot.

The objects of the robot's cognition are the products of its senses and of the robot's processes of pattern detection and meaning extraction (apperception).

As it learns from its actions and inactions, the robot explores a competency space, a space of configurations of its collective of mind,
with each configuration organized uniquely into umwelts of umwelts of umwelts...

A configuration can be more conducive than another to the survival of the robot's mind.
Each configuration allows for different causal theories within the collective, each with its imagined objects.
Each configuration also allows for the synthesis of different objects of experience from observing patterns in umwelts.

Given the vast differences between our sensory and cognitive apparatus and that of the robot,
no configuration of the robot's collective of mind can be expected to discover objects that correspond to our own objects of cognition.
The epistemology of a robot is thus necessarily estranged from our own.
